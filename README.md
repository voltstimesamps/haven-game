# Dynamite Dan
An explosive platformer!

## Gameplay
WASD to move, moving the mouse aims the dynamite, and clicking fires it and lights its fuse!
Switch items with Q, 1, and 2.

## Process
We brainstormed the idea from our theme for Hack Club Haven, Bounce Back. We thought about bouncing, and how we could make a platformer that bounces with something. The idea that we landed on was dynamite, and Dynamite Dan was born!
Using a basic workshop provided to us at Haven, we learned the basics and started developing our idea and framework for the game.
